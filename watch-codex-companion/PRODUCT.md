# Watch Codex companion

An experimental native iPhone + Apple Watch client for reading an existing Codex thread, sending a short instruction and targeting the exact active turn when stopping.

The real connection route is now wired in source, with a separate optional demo. No successful real connection is claimed. Public third-party protocol evidence is not provider approval, current service compatibility or a passed Apple build.

No extra host bridge, desktop credential import, new thread/fork, permission/model/cwd override, background command queue or automatic mutation replay. Credentials remain on iPhone. Explicit native confirmation is required for login, enrollment, pairing, host selection and mutations. Unknown results remain locked for deliberate review.

Primary audience: a Chinese-speaking developer checking work in short moments. This candidate requires the iPhone in the foreground and unlocked. See Docs/LIVE_CONNECTION.md for limits and unrun acceptance checks.
